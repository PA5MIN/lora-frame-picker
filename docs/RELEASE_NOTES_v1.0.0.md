# v1.0.0 首个公开版 / First public release

## 中文

LoRA 数据集筛帧器 v1.0.0 是首个公开发布版，面向不熟悉 Python 和命令行的普通用户。

主要内容：

- Windows 10/11 x64 图形化安装器
- Apple Silicon 和 Intel Mac 拖放安装 DMG
- 视频播放、时间轴定位、逐帧浏览和 JPEG 导出
- 图片比例裁剪、原图导出和批量去黑边
- 受随机口令保护的手机局域网 WebUI
- 中英文文档、自动测试、隐私扫描和跨平台构建工作流

注意：当前安装包未购买商业代码签名或 Apple 公证，首次启动可能出现系统安全提示。

## English

LoRA Frame Picker v1.0.0 is the first public release, designed for regular users who do not want to manage Python environments or command-line dependencies.

Highlights:

- Graphical Windows 10/11 x64 installer
- Drag-to-install DMGs for Apple Silicon and Intel Macs
- Video playback, timeline seeking, frame stepping, and JPEG export
- Aspect-ratio cropping, original-image export, and batch black-border removal
- Phone LAN WebUI protected by a new random access key on every run
- Chinese and English documentation, automated tests, privacy auditing, and cross-platform build workflows

Note: the current packages are not commercially code-signed or Apple-notarized, so the operating system may display a security warning on first launch.
